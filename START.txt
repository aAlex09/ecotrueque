🚀 CÓMO EMPEZAR (3 pasos)

1. Terminal 1 - Backend:
   cd backend
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   cp .env.example .env
   python init_db.py
   uvicorn app.main:app --reload

2. Terminal 2 - Frontend:
   cd frontend
   npm install
   npm start

3. Accede:
   http://localhost:8000/docs
   http://localhost:4200
